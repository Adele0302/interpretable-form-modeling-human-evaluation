# Public Data Release

This directory contains compact, aggregate or metadata-level research outputs selected for public inspection.

It intentionally does **not** contain raw participant records, original source images, or the complete geometric matrices.

- `geometry/`: sample counts and PCA explained-variance summary.
- `ratings/`: rating-study QC counts.
- `modeling/`: final leakage-aware model summaries.
- `pairwise/`: aggregate independent 2AFC results.
- `interaction/`: condition-level outcomes from the 18-participant within-subject study.

See `../docs/PRIVACY_AND_DATA_RELEASE.md` for the release policy and `../docs/DATA_DICTIONARY.md` for field definitions.
