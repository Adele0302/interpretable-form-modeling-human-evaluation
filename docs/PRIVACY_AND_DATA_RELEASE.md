# Privacy and Data-Release Policy

This public repository follows a **data-minimization** approach for human-subject research artifacts.

## Publicly released

- derived geometric representations;
- aggregate item-level rating statistics;
- final leak-free model-performance summaries;
- aggregate 2AFC comparison statistics;
- experimental interface source code and public scientific configuration;
- analysis and verification scripts.

## Not publicly released

- participant-level behavioral logs from the 18-person interaction study;
- raw individual 2AFC response rows;
- raw questionnaire exports;
- real session identifiers and collected event histories;
- names, contact information, IP addresses, signatures, or consent records;
- private mapping keys;
- SQLite databases created during data collection;
- original source images whose redistribution rights are not established.

The absence of participant-level data is intentional. Public transparency is provided through the experimental design, code, derived/aggregate tables, methods documentation, and reproducible verification checks without unnecessarily disclosing human-subject records.
